# Глеб — личная визитка

Живая версия: **https://manicbylmenqwe-dev.github.io/gleb-card/**

Мини-сайт с контактами: Telegram, MAX и телефон. Сделан по образцу
[zakhar-card](https://pirotekhnik163.github.io/zakhar-card/).

## Что внутри

- `index.html` — разметка визитки
- `style.css` — оформление, 3D-наклон, адаптив
- `app.js` — звуки, копирование, vCard, QR-код, «Поделиться»
- `qrcode.min.js` — генератор QR-кодов
- `avatar.png` — фото профиля

## Публикация

Сайт статический: достаточно открыть `index.html` локально или включить
GitHub Pages для ветки `main` (папка `/`, корень репозитория).

## Как поменять данные

Имя, ник, ссылки и телефон встречаются в `index.html` и `app.js`
(vCard, QR-коды, текст «Поделиться»). Фото — `avatar.png` (квадратное, лучше 600×600).
